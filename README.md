# Beginner Task 1: Image Tagging Classifier

## 📌 Project Overview
Developed a Convolutional Neural Network (CNN) designed to automatically classify images into categorical labels using the CIFAR-10 dataset.

* **IDE:** Anaconda Spyder (Python 3.13)
* **Core Frameworks:** TensorFlow / Keras
* **Libraries:** NumPy, Matplotlib

## 📊 Model Status
